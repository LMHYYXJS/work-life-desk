## 1. 这次网站只需要做什么

在个人网站上增加**一个入口**：

- 入口名称：`开源项目 · 工作生活台`
- 入口形式：卡片、按钮或项目列表中的一项都可以
- 点击后：前往 GitHub 仓库或项目详情页
- 建议位置：`library.html` 的「我的世界时间线」入口下面，或网站现有的「作品 / 项目」区域
- **不要**嵌入本地 App、不要使用 `localhost`、不要复制 App 的后台代码

网站负责视觉和页面结构；App 和 GitHub 由 App 这边准备。

## 4. 项目详情页文案

### 短版（适合入口卡或首页一句话）

```text
工作生活台是一个本地优先的个人工作与生活控制台：9 个模块，覆盖任务、自媒体、开发、咨询、健身、饮食与游戏记录；不联网、不登录，数据全部保存在本机。
```

### 长版（适合项目详情页开头）

```text
工作生活台（Work Life Desk）是我自己做的本地个人工具。

它把平时容易散落在不同软件里的几件事——今天要做什么、自媒体内容做到哪一步、开发项目卡在哪、最近有没有训练、吃了什么——放进一个浏览器界面里。后台是一个只监听本机的 Python 服务，数据写在本地的 JSON 文件里，不联网、不登录、没有云数据库。

它不是要替代 Notion 或 Excel，也不是一个商业产品。它更像一个可以自己改、自己备份、自己带走的私人工作台。

项目采用 MIT License 开源。Windows 用户可以直接下载一键包，解压后双击启动；源码也在 GitHub 上，方便大家改成适合自己的版本。
```

## 5. 下载与安装说明（可放详情页）

### Windows 10/11 x64（推荐）

```text
1. 打开 GitHub Releases 页面
2. 下载 工作生活台-v1.0.0-Windows-x64.zip
3. 解压到一个有写入权限的文件夹，例如 D:\工作生活台
4. 双击「启动.bat」
5. 浏览器会自动打开；如果没有，访问 http://127.0.0.1:8848/
6. 关闭后台服务：双击「关闭.bat」
```

说明：

- 一键包已自带 Python 3.13 运行时，不需要另外安装 Python。
- 第一次启动会在 `data/` 下生成 `data.json`，不会包含作者的真实数据。
- 数据只保存在本机，备份在 `data/backups/`。

### macOS / Linux

```text
目前没有提供一键包。
需要自行安装 Python 3.13，然后在项目目录运行：
python app/server.py
```

请如实写明：Mac/Linux 未做完整适配测试；手机端不支持。

### 重要说明

- **不要写“手机 App”或“App Store 下载”。** 这是 Windows 本地工具。
- **不要写“云同步”“在线使用”“自动抓取平台数据”。** 这些都不是当前功能。
- 自媒体图表数据是手动录入的，不联网抓取。

## 7. FAQ 文案

```text
Q：这是手机 App 吗？
A：不是。它是 Windows 本地工具，通过本机浏览器界面使用；手机端不支持。

Q：需要登录吗？
A：不需要。没有账号系统，也没有云同步。

Q：我的数据会上传吗？
A：不会。服务只监听 127.0.0.1，数据保存在本机的 data/data.json。

Q：需要安装 Python 吗？
A：下载 Windows 一键包不需要；包内已自带运行时。源码运行需要 Python 3.13。

Q：Mac 能用吗？
A：目前没有 Mac 一键包，需要自行安装 Python 3.13 运行服务端；未做完整适配测试。

Q：为什么杀毒软件会提示？
A：程序包含未签名的 .bat 和 Python 运行时，可能被 SmartScreen 标记为未知发布者。它只监听本机，不联网；请从官方 GitHub Releases 下载。
```

## 8. 视觉建议（不是硬性要求）

- 这个项目适合“作品 / 开源项目”气质，不需要做成电商落地页。
- 可以使用深色界面截图作为卡片封面，和网站现有视觉做呼应。
- 入口卡不要堆太多字：标题 + 一句话 + 一个按钮即可。
- 如果网站有项目详情页，再把功能列表、截图和安装说明展开。
- **不要使用天气元素、天空、云、太阳、月亮、星星、雨雪或城市剪影**；这个 App 的视觉语言是 Liquid Glass，不是天气 App。
